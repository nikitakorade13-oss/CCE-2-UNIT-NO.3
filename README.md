# College-Lab-Equipment-Allocation-System-

## Problem Statement 
To Develop College Lab Equipment Allocation System using Circular Linked List. 

## Objective
To develop a C++ based system for managing students waiting for lab equipment. The system uses a Circular Linked List to maintain the waiting queue efficiently. It allows adding students, allocating equipment and displaying the waiting list. The project demonstrates the practical use of Circular Linked Lists in a real world application.

## Introduction 
The College Lab Equipment Allocation System using Circular Linked List is a C++ project designed to manage the allocation of laboratory equipment to students in a college. In this system, students can be added to a waiting list, and equipment is allocated to them in a systematic manner. A circular linked list is used to maintain the student records, where the last node points back to the first node. This allows the system to process students in a circular order. The system helps reduce manual work, improves equipment management, and ensures fair allocation of laboratory equipment to students.

## Algorithm 
1.Start the program and initialize “rear = NULL”.
2.Display the menu and accept the user’s choice.
3.If the choice is 1 ,enter the student roll number and name, create a new node, and insert it at the rear of the circular linked list.
4.If the choice is 2, allocate equipment to the first waiting student and remove that student from the queue.
5.If the choice is 3, display all students in the waiting queue.
6.If the choice is 4, exit the program.
7.Repeat the menu until the user selects Exit.
8.Stop the program.

## Result
The College Lab Equipment Allocation System was successfully designed and implemented using C++ and a Circular Linked List. The system allows users to add students, allocate laboratory equipment, and display the waiting list. It provides an organized and efficient way to manage laboratory equipment allocation.

## Conclusion 
The College Lab Equipment Waiting and Allocation System is implemented using C++ and a circular linked list. It manages students in FIFO (First In, First Out) order and provides options to add students, allocate equipment, and display the waiting list. This project helps understand circular linked lists, pointers, and dynamic memory allocation.
